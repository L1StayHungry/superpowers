## Implementer Dispatch Prompts

Do **not** paste or summarize on-disk briefs, plans, specs, or context. If a file exists, reference its path and require the implementer to read it. Code blocks are **not** exempt.

Prompt must foreground:
1. Brief path to read
2. Exact task invocation
3. Required report path

Example: “Read `/tmp/sdd/task-03-brief.md`, implement the task, then write your report to `/tmp/sdd/task-03-report.md`.”
