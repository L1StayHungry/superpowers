### Implementer Dispatch Prompts

When a task brief exists on disk, do **not** restate or summarize it—neither prose nor code block. Send only:

- the brief path to read
- the exact task invocation/role
- the required report path to write
- any truly new constraints not already in the brief

Put report path and invocation near the top. If context feels important, add it to the brief, not the dispatch prompt.
