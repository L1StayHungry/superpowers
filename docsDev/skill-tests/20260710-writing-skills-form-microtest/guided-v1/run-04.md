### Implementer Dispatch Prompt Contract

When a task brief exists on disk, the dispatch prompt contains only:

1. Task brief path to read: `/tmp/sdd/task-03-brief.md`
2. Required invocation/command, if any
3. Required report path: `/tmp/sdd/task-03-report.md`
4. Instruction to complete the brief and write the report

Do not paste or summarize the brief, plan, spec, or context. Code blocks follow the same rule: include only new information not already in the brief.
